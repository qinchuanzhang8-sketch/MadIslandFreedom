================================================
 疯狂岛·自由模组 (MadIslandFreedom) v1.3.0
 适配：疯狂岛 Mad Island（Unity 2021.3）
 基于 BepInEx 5.4.23.2 + HarmonyX
================================================

【这是什么】
一个功能型模组包，包含三大功能：

一、作弊菜单（游戏中按 F8 开关）
  1. 物品页：完整收录游戏全部物品（1797+ 种，含隐藏物品），
     · 支持中文输入法直接打字搜索（如"剑/药/衣服"），也支持粘贴；
     · 21 个分类按钮一键筛选（资源/工具/建筑/服饰/食物...）；
     · 超长分类自动分页，每页 200 个，完全显示不截断；
     · 每行【给1】【给N】直接刷取（非堆叠物品自动限制 1 个防坏档）。
  2. 刷怪页：全部怪物/NPC/BOSS 可搜索可翻页，【刷1】【刷N】刷到身边。
  3. 角色状态页：可对任意角色（当前/男主/女主/最近的NPC/面板选中）
     修改 20 项数值（生命/气绝/攻击/速度/等级/经验/道德/躁动/媚药/
     好感/怀孕等），每项支持【锁定】（锁定后数值恒定）；
     附一键满血/打晕/好感MAX/设为怀孕/全体同伴满状态等快捷按钮。
  4. 设置页：女主必定怀孕开关、解除全部锁定、重新扫描等。

二、男主 × 女主 互动解锁
  打开对方的人物面板即可看到【性爱】选项，与普通 NPC 完全一致
  （原版该机制被"设置限制开关 + 主线进度"锁定，本模组已放开，
   其余角色的原版判定不受影响）。
  提示：若对方拒绝（走开），在角色状态页给她【媚药开】或【好感MAX】即可。

三、女主怀孕 / 分娩解锁（与其他女性角色相同流程）
  · 与男性"中出"结算后按原版概率怀孕（男主 3 倍率；可在设置页开 100%）；
  · 怀孕进度每周期自动推进（12 格），进度到 0 即临产；
  · 临产时：切换操作女主对【产床】交互分娩，或用男主打开她的面板分娩；
    孩子自动出生并成为同伴（继承母亲外观）；
  · 怀孕中可用原版【堕胎药】解除。

【安装方法】
方法一（推荐）：
  把 MOD_FILES 文件夹里面的所有内容复制到游戏根目录
  （与 Mad Island.exe 同一文件夹），提示覆盖时选"是"。
方法二（一键脚本）：
  把整个文件夹移动到游戏根目录，双击运行 install.bat。

安装后直接启动游戏即可。F8 打开/关闭作弊菜单。
（快捷键可在 BepInEx\config\madisland.freedom.cfg 修改）

【卸载方法】
把 uninstall.bat 放入游戏根目录双击运行；
或手动删除以下四项即完全还原：
  winhttp.dll、doorstop_config.ini、.doorstop_version、BepInEx 文件夹
（只关闭模组：删除 BepInEx\plugins\MadIslandFreedom 文件夹）

【注意事项】
1. 建议先备份存档：StreamingAssets\XML\SaveData*.xml
2. 本模组不修改游戏本体文件，完全可逆。
3. 包含 BepInEx 5.4.23.2（LGPL-2.1 许可，见 LICENSE-BepInEx.txt）。
4. 日志：BepInEx\LogOutput.log
